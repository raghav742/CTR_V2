# CTR_V2

Firmware (Arduino Mega 2560) and laptop control centre for the Concentric Tube Robot V2
demonstrator, Benchmark Electronics Almelo.

- **Start here:** [`docs/HANDOVER.md`](docs/HANDOVER.md) — status, setup, V2 bring-up, recommendations
- **Operating the robot:** [`docs/USER_MANUAL.md`](docs/USER_MANUAL.md)
- **How the firmware works:** [`docs/architecture.md`](docs/architecture.md), decisions in [`docs/decisions.md`](docs/decisions.md)
- **Laptop control centre:** [`laptop/README.md`](laptop/README.md)

Build with PlatformIO: environment `v1` (V1 robot) or `v2` (V2 robot, prepared).
Firmware 5.0.0 has not run on a robot yet; the last robot-tested version is tag
`v4.3.1-tested` (see `docs/HANDOVER.md`).
